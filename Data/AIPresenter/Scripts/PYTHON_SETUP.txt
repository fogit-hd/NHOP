================================================================================
  Python setup for NHOP AI Presenter (Windows)
================================================================================

This project uses Python for (UiPath invokes `pyw` for no console window):
  - resolve_default_microphone.py  — default mic name when ai_settings has
    "microphone_name": "default" (requires pycaw).
  - elevenlabs_tts.py              — ElevenLabs TTS to WAV (stdlib).
  - play_response_audio.py — plays response.wav and blocks until the end (uses
    ffplay.exe next to ffmpeg.exe if present: copy both from the same ffmpeg build).
  - open_default_app.py — opens a slide/video file with the default Windows app
    (os.startfile), used instead of cmd.exe /c start.
  - slides_from_pptx.py — ensures empty Data\AIPresenter\Input\slides.txt,
    Data\AIPresenter\Input\gpt_slide_content.txt, and Temp\gpt_slide.txt exist
    if missing; prioritizes configured PPTX path, then ordered list in
    Data\AIPresenter\Input\pptx_run_order.xlsx (or
    Data\AIPresenter\Input\pptx_run_order_template.csv), then PPTX in
    Data\AIPresenter\Input\pptx_file_here, then PPTX in Data\AIPresenter\Input,
    and falls back to slides.csv if needed.
    (slide_index, slide_title, slide_path relative to project root), sorts by
    index, writes Temp\slides_iterate.tsv for slide iteration.

--------------------------------------------------------------------------------
0. Windows: avoid “Is this file from a trusted source?” on slide images
--------------------------------------------------------------------------------

  Slide photos copied from a zip or downloaded from the web carry “Mark of the
  Web.” Windows may prompt before opening them. The presenter runs
  `Unblock-File` on each path automatically in open_default_app.py before
  `os.startfile`.

  To clear MOTW for the whole folder once (PowerShell, from project root):

    Get-ChildItem -Path "Data\AIPresenter\Input\photos" -Recurse -File | Unblock-File

  Or unblock a single file:  Unblock-File -LiteralPath "full\path\to\slide_03.jpg"

--------------------------------------------------------------------------------
1. Install Python 3 (if not already installed)
--------------------------------------------------------------------------------

  Option A — Recommended on Windows: install from https://www.python.org/downloads/
    During setup, enable "Add python.exe to PATH" if you want the `python` command.

  Option B — Microsoft Store: search for "Python 3.x" and install.

  After installation, open PowerShell or Command Prompt and verify:

    py --version

  The `py` launcher works even when `python` is not on PATH.

--------------------------------------------------------------------------------
2. Upgrade pip (optional but recommended)
--------------------------------------------------------------------------------

  From the project root (or any folder):

    py -m pip install --upgrade pip

  If you see a warning that pip.exe is installed in a Scripts folder "not on PATH",
  you can ignore it as long as you always use:

    py -m pip <command>

  That avoids needing pip.exe on PATH.

--------------------------------------------------------------------------------
3. Install project Python dependencies
--------------------------------------------------------------------------------

  From the NHOP Project root directory, run:

    py -m pip install -r Data\AIPresenter\Scripts\requirements-aipresenter.txt

  This installs:
    - pycaw (and its dependencies: comtypes, psutil) for default microphone name
      resolution used by resolve_default_microphone.py.
    - openpyxl for reading ordered PPTX list from pptx_run_order.xlsx.
      (If openpyxl is unavailable, pptx_run_order_template.csv still works.)

  Verify:

    py -c "import pycaw; print('pycaw OK')"

--------------------------------------------------------------------------------
4. UiPath runtime notes
--------------------------------------------------------------------------------

  -   Workflows call the Python launcher as `pyw` by default (no console window
  during presentation). `pyw` is installed next to `py` when you install Python from
  python.org. If `pyw` is missing, set the workflow variable to `py` or the full
  path to pythonw.exe on that machine.

  - Run the robot from a context where the same user has installed packages with
    `py -m pip` (per-user installs apply to that Windows account).

--------------------------------------------------------------------------------
5. resolved_microphone_name.txt (Temp folder)
--------------------------------------------------------------------------------

  When ai_settings.json has "microphone_name": "default", the workflow runs
  resolve_default_microphone.py before each recording and overwrites:

    Data\AIPresenter\Temp\resolved_microphone_name.txt

  That file is a runtime cache of the current Windows default capture device name.
  Do not treat it as fixed configuration; do not commit it to source control if you
  use Git (see .gitignore).

--------------------------------------------------------------------------------
6. Pipeline: Vision extract + GPT slide script (AIInteractivePresenter Init)
--------------------------------------------------------------------------------

  After slides_from_pptx.py builds slides_iterate.tsv, UiPath runs:

    pyw Data\AIPresenter\Scripts\pipeline_extract_and_compose.py --root "<project>"

  This prioritizes configured PPTX input, then ordered PPTX list in
  Data\AIPresenter\Input\pptx_run_order.xlsx (or
  Data\AIPresenter\Input\pptx_run_order_template.csv), then PPTX in
  Data\AIPresenter\Input\pptx_file_here, and falls back to
  Data\AIPresenter\Input\slides.csv when needed.
  In CSV mode, it calls OpenAI Vision on each image and appends each slide block
  to a single file
  Data\AIPresenter\Temp\extracted_slides_raw.txt (flushed after each slide),
  then calls GPT with Data\AIPresenter\Input\presentation_master_prompt.txt
  to produce a single composed script:
  Data\AIPresenter\Input\gpt_slide_content.txt (=== SLIDE | n | title ===
  blocks). UiPath slices that file per slide; no per-slide narration files.

  Requires valid openai_api_key in Data\AIPresenter\Config\ai_settings.json.
  Optional: openai_vision_model (default gpt-4o).

--------------------------------------------------------------------------------
