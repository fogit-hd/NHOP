PPTX Run Order Queue (English Guide)

This folder supports running multiple PPTX files in one robot run.

Queue file name
- Data/AIPresenter/Input/pptx_run_order.xlsx
- Data/AIPresenter/Input/pptx_run_order_template.csv

Required columns in row 1
- run_order
- pptx_path
- enabled

Column rules
- run_order: integer (1, 2, 3...). Smaller values run first.
- pptx_path: absolute path or relative path.
  Relative path can be resolved from:
  - project root
  - Data/AIPresenter/Input/pptx_file_here
  - Data/AIPresenter/Input
- enabled: TRUE/FALSE (also accepts 1/0, yes/no, on/off).

How to use
1. Open Data/AIPresenter/Input/pptx_run_order_template.csv in Excel.
2. Edit rows and values as needed.
3. Use either option:
  - Keep using pptx_run_order_template.csv directly, or
  - Save as Data/AIPresenter/Input/pptx_run_order.xlsx.
4. Keep header names unchanged.
5. Set enabled = TRUE for files you want to run.
6. Run the robot.

Behavior notes
- If two rows have the same run_order, they are sorted by file path.
- Duplicate PPTX paths are processed once.
- If the queue file exists but no valid rows are resolved, the flow falls back to folder auto-detection.
