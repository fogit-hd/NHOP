API KEYS GUIDE (OpenAI + ElevenLabs)
====================================

1) OpenAI API Key (for Whisper + GPT)
-------------------------------------
Where to get:
- https://platform.openai.com/api-keys

Steps:
1. Sign in to OpenAI platform.
2. Go to API Keys.
3. Click "Create new secret key".
4. Copy the key immediately (it is shown once).

Put into config:
- File: Data\AIPresenter\Config\ai_settings.json
- Field: "openai_api_key"


2) ElevenLabs API Key (for TTS)
-------------------------------
Where to get:
- https://elevenlabs.io  (Profile/Settings -> API Keys)

Steps:
1. Sign in to ElevenLabs.
2. Open API Keys section.
3. Create/Copy your xi-api-key.

Put into config:
- File: Data\AIPresenter\Config\ai_settings.json
- Field: "elevenlabs_api_key"


3) ElevenLabs Voice ID
----------------------
Where to get:
- ElevenLabs Voice Library or your voice list.
- Open a voice details page and copy voice_id.

Put into config:
- File: Data\AIPresenter\Config\ai_settings.json
- Field: "elevenlabs_voice_id"


Important
---------
- Keys are NOT auto-generated by workflow.
- Do not commit real keys to source control.
- If key is exposed, rotate/regenerate it immediately.
